# 演示说明

## 演示目标

展示语音输入法助手从录音、识别、文本处理到历史记录的完整链路，说明项目在准确率、易用性、响应速度和成本控制方面的设计。

## 运行环境

- Go 1.24 或以上版本。
- Windows 浏览器，推荐 Chrome 或 Edge。
- 可用麦克风。
- 腾讯云 ASR 密钥配置文件，路径为仓库上一级目录的 `voiceinput.local.json`。

## 启动步骤

1. 进入项目目录。

```powershell
cd D:\prosoft\package\goproject\LanguageInput\seven_cows
```

2. 启动服务。

```powershell
go run ./cmd/voiceinput
```

3. 打开本地页面。

```text
http://127.0.0.1:8080
```

## 演示流程

1. 检查页面显示“准备就绪”。
2. 按住录音按钮，说一句中文短句。
3. 松开按钮，等待识别结果返回。
4. 查看文本框中的识别结果。
5. 点击“处理文本”，验证语气词清理、口令转换和自动标点。
6. 点击历史记录中的条目，验证结果可回填。
7. 点击“复制”，验证文本可复制到其他输入框。

## 建议演示语句

```text
嗯 今天下午三点开项目会议 逗号 请大家准时参加 换行 谢谢
```

预期处理结果：

```text
今天下午三点开项目会议，请大家准时参加
谢谢。
```

## 异常处理检查

- 如果 8080 端口被占用，可使用 `go run ./cmd/voiceinput -addr 127.0.0.1:8081`。
- 如果腾讯云密钥未配置，项目会使用 mock 模式验证完整流程。
- 如果浏览器未授权麦克风，页面会提示录音失败，需要在浏览器地址栏重新允许麦克风权限。
